## Going back to an older version

1. Quit Lesson Notes (menu-bar icon → **Quit Lesson Notes**).
2. Download the DMG for the version you want from the table above and drag the app onto **Applications**,
   replacing the current one.

Older versions read the same data folder. Going back past a version that changed the data format (1.2 and 1.6)
is not recommended; the app keeps a verified backup before every migration.
